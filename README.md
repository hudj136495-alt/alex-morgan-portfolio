# Alex Morgan — Designer Portfolio Concept

A fictional portfolio website for Alex Morgan, an independent visual designer based in London. This concept project demonstrates a modern, minimalist landing page and portfolio presentation for a creative professional. Alex Morgan, the biography, and all featured projects are fictional; the project examples are concepts rather than real client work.

## Features

- Responsive single-page layout for desktop and mobile screens
- Modern minimalist visual design
- Portfolio showcase with three fictional concept projects
- Mobile-friendly navigation linking to each page section
- Clean, semantic HTML structure

## Technologies

- HTML5
- CSS3
- JavaScript

## Design Direction

The visual direction takes cues from editorial design, with a minimalist layout and typography-led hierarchy. A warm, neutral palette provides the foundation, while restrained cobalt blue accents draw attention to links and key details.

## Project Purpose

This project demonstrates skills in designing and building personal websites and landing pages for independent creators and small businesses. It is intended as a concept portfolio piece for presentation to potential international clients.

## Project Files

- `index.html` — semantic page content and section structure
- `style.css` — responsive layout and visual styling
- `app.js` — reserved for future interactive enhancements
